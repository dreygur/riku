# ui

Generic UI primitives generated with the shadcn CLI (`components.json`, style
`radix-nova`), most of them wrapping `radix-ui` and styled with `cn` from
`lib/utils.ts`. Keep Riku-specific logic in `../riku`.

Files: `alert-dialog`, `badge`, `button`, `card`, `command`, `dialog`,
`dropdown-menu`, `input-group`, `input`, `scroll-area`, `select`, `separator`,
`sheet`, `skeleton`, `sonner` (toasts), `table`, `tabs`, `textarea`, `tooltip`
(all `.tsx`).
